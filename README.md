# **Трекер звичок "Турбота про себе" (Self-Care Tracker Bot)**

Це консольний асинхронний Telegram-бот, створений для підтримки людей, які переживають складні життєві періоди, депресивні чи тривожні стани. Бот допомагає крок за кроком відновлювати щоденну рутину, відстежувати корисні звички, отримувати психологічну підтримку, мотиваційні цитати та наочно бачити свій прогрес у вигляді графіків.

## **🌟 Основний функціонал**

* **Індивідуальний трекер:** Можливість відмічати виконані звички на сьогодні.  
* **Гнучке керування:** Користувач може додавати власні звички, переглядати список активних та видаляти непотрібні.  
* **Дефолтний набір "Маленькі кроки":** Бот одразу пропонує базові звички для підтримки життєдіяльності (сон, гігієна, застелене ліжко, прогулянка, ліки, їжа).  
* **Психологічна підтримка та поради:** Ментальні поради та теплі слова підтримки при виконанні завдань.  
* **Розумна система мотивації:** Якщо користувач виконує **понад 70%** запланованих звичок за день, бот щиро хвалить його, створюючи позитивне підкріплення.  
* **Аналітичні звіти (Matplotlib \+ Pandas):** Генерація та надсилання візуальних графіків прогресу за тиждень прямо в чат.  
* **Збереження даних:** Автоматичний запис та зчитування стану з JSON-файлу.

## **🛠️ Використані модулі курсу та технології**

* **ООП (Об'єктно-орієнтоване програмування):** Створено класи моделей та сервісів зі строгою типізацією (Type Hints).  
* **Робота з файлами (JSON):** Надійне збереження даних з обробкою виняткових ситуацій (try/except).  
* **Аналіз даних (Pandas):** Використовується для агрегації щоденної статистики.  
* **Візуалізація даних (Matplotlib):** Побудова лінійних та стовпчикових графіків успішності.  
* **Тестування (Pytest):** Покриття бізнес-логіки юніт-тестами.

## **🚀 Як запустити проєкт**

1. **Клонуйте репозиторій або завантажте файли:**  
   git clone https://github.com/chebanoleksandra/oleksandra\_mh\_bot.git  
   cd project\_name

2. **Встановіть залежності:**  
   pip install \-r requirements.txt

3. **Налаштуйте токен бота:**  
   Отримайте токен у @BotFather в Telegram і збережіть його в системні змінні оточення або впишіть у файл bot.py (значення BOT\_TOKEN).  
   *Рекомендовано через термінал:*  
   * **Linux/macOS:** export BOT\_TOKEN="ваш\_токен"  
   * **Windows (cmd):** set BOT\_TOKEN="ваш\_токен"  
   * **Windows (PowerShell):** $env:BOT\_TOKEN="ваш\_токен"  
4. **Запустіть бота:**  
   python bot.py

5. **Запуск тестів:**  
   python \-m pytest test\_project.py
